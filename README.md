PANDUAN PENGGUNAAN LENGKAP — AI ASSESSMENT STUDIO

Pembuat / Pengembang: Darmawan, S.Pd., M.Si (Guru Fisika SMAIT Buahati Islamic School Mamuju)

Platform: Multi-Format Question Generator (.DOCX & .PPTX)

1. Pendahuluan

AI Assessment Studio adalah aplikasi berbasis web yang dirancang khusus untuk membantu pendidik (guru, dosen, dan instruktur) dalam menyusun paket soal asesmen akademik, kisi-kisi, kartu soal, kunci jawaban, rubrik penilaian, lembar jawaban (LJK), serta slide presentasi interaktif secara cepat dan profesional.

Seluruh file hasil akhir dapat diunduh dalam format Microsoft Word (.docx) dan Microsoft PowerPoint (.pptx) asli yang dapat dibuka dan diedit sepenuhnya di perangkat lunak Microsoft Office.

2. Alur Kerja Utama (Workflow)

Alur penggunaan dirancang sangat intuitif dan mudah tanpa memerlukan keahlian teknis khusus:

Konfigurasi Soal: Pilih jenjang pendidikan, kelas, mata pelajaran, materi pokok, tujuan pembelajaran, level Taksonomi Bloom (C1–C6), tingkat kesulitan, dan jenis soal.

Generate Soal dengan AI: Klik tombol Generate, dan AI akan menyusun butir soal berkualitas tinggi beserta stimulus grafik, tabel data, dan pembahasan.

Pilih Format & Kustomisasi: Tentukan komponen dokumen Word (A4/F4, 1/2 kolom, kop sekolah) dan template PowerPoint (Student Mode atau Teacher Mode).

Preview & Editor Interaktif: Tinjau hasil halaman Word, slide presentasi, atau edit butir soal, geser urutan, ganti grafik/tabel sesuai kebutuhan.

Ekspor File Office: Unduh file .docx dan .pptx asli dengan satu kali klik.

3. Panduan Langkah demi Langkah

A. Konfigurasi Soal (Tab 1)

Jenjang Pendidikan: Pilih dari pilihan SD/MI, SMP/MTs, SMA/MA, SMK, Perguruan Tinggi, atau Umum/Pelatihan.

Kelas / Semester: Dropdown akan menyesuaikan secara otomatis (misalnya Kelas 1–6 untuk SD, Kelas 7–9 untuk SMP, Kelas 10–12 untuk SMA, hingga Semester 1–8 untuk Perguruan Tinggi).

Mata Pelajaran: Pilihan mapel akan muncul otomatis sesuai jenjang dan kelas. Anda juga dapat menggunakan tombol Tambah Mata Pelajaran Baru jika mapel atau muatan lokal belum tersedia.

Materi Pokok & Tujuan Pembelajaran: Masukkan topik bahasan (contoh: Hukum Newton tentang Gerak). Klik tombol Susun Otomatis dari Materi untuk menghasilkan kalimat Tujuan Pembelajaran (TP) yang selaras dengan kurikulum.

Taksonomi Bloom (C1–C6): Pilih tingkat kognitif yang diinginkan (dapat mencentang beberapa level sekaligus, atau klik Pilih Fokus HOTS untuk C4–C6).

Jenis Soal & Komponen Stimulus: Pilih format soal (Pilihan Ganda, Uraian/Essay, Campuran, AKM) dan centang komponen visual seperti Grafik, Tabel, atau Rumus Fisika/Matematika.

B. Pilih Format Hasil Akhir (Tab 2)

Microsoft Word (.docx):

Pilih komponen dokumen yang disertakan: Naskah Soal, Kunci Jawaban, Pembahasan, Kisi-Kisi, Kartu Soal, Rubrik Penilaian, dan Lembar Jawaban (LJK).

Atur tata letak: Ukuran Kertas (A4 / F4), Orientasi (Portrait / Landscape), Kolom (1 atau 2 kolom), Jenis Font (Times New Roman, Calibri, Arial, Cambria), serta Margin.

Sesuaikan Kop Sekolah, Nama Guru, dan Logo Instansi.

Microsoft PowerPoint (.pptx):

Mode Presentasi: Pilih Student Mode (soal interaktif tanpa kunci jawaban untuk kuis kelas) atau Teacher Mode (lengkap dengan kunci jawaban, pembahasan, level Bloom, skor, dan indikator).

Tema Desain: Pilih dari 5 pilihan template profesional (Minimalis Elegan, Futuristik Teknologi, Akademik Profesional, Colorful Education, Modern 3D Learning).

C. Sistem Preview & Editor Interaktif (Tab 3)

Preview Halaman Word: Menampilkan simulasi persis lembar kertas A4/F4 dengan kop surat resmi, header, footer, dan nomor halaman.

Preview Slide PowerPoint: Menampilkan player slide 16:9 interaktif lengkap dengan navigasi slide, tombol Student/Teacher Mode, serta Catatan Presenter (Speaker Notes).

Editor Soal Interaktif:

Klik Edit Soal / Grafik / Tabel pada butir soal mana pun untuk mengubah narasi, opsi, rumus, atau menyunting data grafik batang dan tabel pengamatan secara langsung.

Gunakan tombol panah atas/bawah untuk mengubah urutan soal, atau klik Tambah Soal Baru untuk memperkaya paket asesmen.

4. Tips & Trik Penulisan Rumus Tanpa LaTeX

AI Assessment Studio menggunakan Standar Simbol Unicode sehingga rumus Matematika, Fisika, dan Kimia langsung tampil rapi, jelas, dan siap cetak tanpa kode LaTeX (dilarang menggunakan tanda $, \frac, \sqrt, _, atau ^).

Gunakan tombol cepat simbol pada modal editor: ∑ (Sigma), Δ (Delta), √ (Akar), ½ (Pecahan), × (Perkalian), ÷ (Pembagian), ² / ³ (Pangkat), ₁ / ₂ (Subskrip), ° (Derajat), dan → (Panah Vektor).

Contoh penulisan yang benar: ∑F = m × a, Ek = ½ × m × v², a = Δv / Δt, m/s².

Panduan ini disusun untuk mendukung efisiensi penyusunan perangkat evaluasi pembelajaran yang profesional.
